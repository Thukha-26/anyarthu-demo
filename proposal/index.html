၁။အကျဉ်းချုပ်

အညာသူ Express Cargo သည် ရုံးခွဲ ၃ ခု (ရန်ကုန် / စစ်ကိုင်း / အောင်လံ) နှင့် ထိုင်း၊ ကိုရီးယား၊ ဂျပန်၊ ထိုင်ဝမ်၊ တရုတ် လမ်းကြောင်းများကို အိမ်အရောက် ပို့ဆောင်ပေးနေသော လုပ်ငန်းကြီးတစ်ခုဖြစ်သည်။ လက်ရှိတွင် စုံစမ်းမှု၊ ပစ္စည်းစာရင်း၊ ကီလိုဘောက်ချာ၊ ငွေပေးချေမှုနှင့် ပစ္စည်းရောက်ကြောင်း အသိပေးခြင်း အားလုံးကို Messenger၊ Viber၊ ဖုန်းနှင့် လက်ရေးစာရင်း ဓာတ်ပုံများဖြင့် လူကိုယ်တိုင် လုပ်ဆောင်နေရပါသည်။

ကျွန်ုပ်တို့သည် အညာသူ၏ လက်ရှိ လုပ်ငန်းစဉ်အတိုင်း (စာရင်းအရင်ပို့ → အတည်ပြု → ကီလိုဘောက်ချာနှင့် ငွေချေ → ထုပ်ပိုး → ကား/လေယာဉ်တင် → ရောက်ရှိ) ကို မပြောင်းလဲဘဲ အွန်လိုင်းပေါ် တင်ပေးမည့် Website + Online Booking + Shipment Tracking System ကို အဆိုပြုပါသည်။

⭐ အကြံပြု Package: Business Cargo — 3,500,000 Ks (တစ်ကြိမ်) · ပြီးစီးချိန် ၄–၆ ပတ်
လစဉ် All-in starts 2500 THB (Website Subscription များမပါ)

၂။လက်ရှိအခြေအနေနှင့် ဖြေရှင်းပေးမည့်အရာများ

လက်ရှိအခြေအနေSystem ဖြင့် ဖြေရှင်းပုံ
ပစ္စည်းရောက်ကြောင်းကို လက်ရေးစာရင်း ဓာတ်ပုံဖြင့် တင်ရသည် (ဥပမာ ကားတစ်စီးလျှင် ၆၆ ဦးစာ)ကား/လေယာဉ် တစ်စီးချင်းကို Shipment Batch အဖြစ် ဖွင့်၍ တစ်ချက်နှိပ်ရုံဖြင့် ပါဆယ်အားလုံး Status ပြောင်းသည်။ Customer တစ်ဦးချင်း မိမိပစ္စည်းကို ကိုယ်တိုင် ကြည့်နိုင်သည်
"ပစ္စည်း ဘယ်ရောက်ပြီလဲ" မေးခွန်းများကို Messenger တွင် တစ်ခုချင်း ဖြေရသည်Tracking Number သို့မဟုတ် ဖုန်းနံပါတ်ဖြင့် အချိန်မရွေး ကိုယ်တိုင်ရှာနိုင်သည်။ Messenger တွင် Tracking Link တစ်ခု ပို့ရုံသာ
ပစ္စည်းစာရင်းကို Messenger/Viber တွင် စာရိုက်ပို့ရသည်Online Booking Form — ပို့သူ/လက်ခံသူ၊ လမ်းကြောင်း၊ ပစ္စည်းစာရင်း၊ ခန့်မှန်းကီလို ဖြည့်၍ တစ်ခါတည်းပို့၊ Staff ချက်ချင်းသိ
ကီလိုဘောက်ချာကို လက်ဖြင့်တွက်ရသည် (ကိုရီးယား ၅ ကီလို / ၁၀ ကီလို Tier စသည်)ကီလို ရိုက်ထည့်လိုက်သည်နှင့် Tier ဈေးအလိုက် ဘောက်ချာ အလိုအလျောက်ထွက်၊ Print/ပုံဖြင့် Messenger ပို့နိုင်
ဈေးနှုန်းကို ဗီဒီယို/ပိုစတာဖြင့်သာ ကြေညာသဖြင့် ပို့စ်များအောက် ပျောက်သွားသည်လမ်းကြောင်းအလိုက် ဈေးနှုန်းစာမျက်နှာ + ဈေးတွက်စက် — Admin က ဈေးပြောင်းလျှင် ချက်ချင်း Update
Website မရှိသဖြင့် Google တွင် ရှာမတွေ့၊ Facebook, TikTok Page တစ်ခုတည်းအပေါ် မှီခိုနေရသည်ကိုယ်ပိုင် Domain ဖြင့် Website — Google ရှာဖွေမှုတွင် ပေါ်၊ Page ပြဿနာရှိလျှင်လည်း Customer က Website မှ ဆက်သွယ်နိုင်
ရုံးလိပ်စာ၊ ဖုန်းနံပါတ်များသည် Cover ပုံထဲတွင်သာ ရှိရုံးခွဲ ၃ ခု + ထိုင်းဘက် ဆက်သွယ်ရန်ကို Google Map၊ တစ်ချက်နှိပ် ဖုန်းခေါ်၊ Messenger/Viber/TikTok Button များဖြင့် ပြသ
မှာယူပုံအဆင့်ဆင့်၊ တားမြစ်ပစ္စည်းစည်းကမ်းတို့ကို Featured Post တွင်သာ ရှာရသည်"ပစ္စည်းပို့နည်း" နှင့် "တားမြစ်ပစ္စည်း" စာမျက်နှာ

၄။System Feature များ

Customer အတွက် (Public Website — မြန်မာ / English)

  • လမ်းကြောင်းနှင့် ဈေးနှုန်း — ထိုင်း (ကားလမ်း၊ မဲဆောက်)၊ ကိုရီးယား (တိုက်ရိုက်လေယာဉ် — အင်္ဂါ/ကြာသပတေး)၊ ဂျပန်၊ ထိုင်ဝမ်၊ တရုတ်၊ ထိုင်း → မြန်မာ။ ကီလို Tier ဈေး၊ ကြာချိန်၊ ထွက်ခွာမည့်ရက်
  • ဈေးတွက်စက် — လမ်းကြောင်းနှင့် ကီလို ရွေးလိုက်သည်နှင့် ခန့်မှန်းဈေး ပြ
  • Online Booking — ပစ္စည်းစာရင်း အရင်ပို့ရန် Form (လက်ရှိ လုပ်ငန်းစဉ်အတိုင်း)၊ တားမြစ်ပစ္စည်း အတည်ပြုချက်၊ နယ်မှ Bus Gate ပို့သူများအတွက် Pickup ရွေးချယ်မှု
  • Tracking — Tracking Number သို့မဟုတ် ဖုန်းနံပါတ်ဖြင့် ရှာ၊ Status Timeline (စာရင်းရပြီး → ထုပ်ပိုးပြီး → ကား/လေယာဉ်တင်ပြီး → နယ်စပ်/ဆိပ်ကမ်းရောက် → ပို့ဆောင်နေ → ရောက်ရှိ)
  • ပစ္စည်းပို့နည်း / တားမြစ်ပစ္စည်း / FAQ စာမျက်နှာ
  • ရုံးခွဲများ — ရန်ကုန် (ရုံးချုပ်)၊ စစ်ကိုင်း၊ အောင်လံ၊ ထိုင်းဘက် ဆက်သွယ်ရန် — Map၊ ဖုန်း၊ Messenger၊ Viber၊ TikTok
  • ကုမ္ပဏီ လိုင်စင်အခြေအနေ (Aung Shining Star Co., Ltd) ဖော်ပြချက် — ယုံကြည်မှုအတွက်

ဝန်ထမ်းအတွက် (ရုံးခွဲ Staff)

  • Booking လက်ခံ / အတည်ပြု၊ ကီလိုထည့်၍ ဘောက်ချာထုတ် (Tier ဈေး အလိုအလျောက်၊ ကျပ် / ဘတ်)
  • ငွေရ/မရ မှတ်တမ်း (Cash, KBZPay, WavePay, AYA Pay, Bank, Baht)
  • ထုပ်ပိုးပြီးကြောင်း မှတ်တမ်း၊ QR Label Print
  • Shipment Batch — ကား/လေယာဉ် တစ်စီးချင်း (ဥပမာ "နိုဝင်ဘာ ၃ ကား") ဖွင့်၊ ပါဆယ်များထည့်၊ QR Scan သို့မဟုတ် တစ်ချက်နှိပ်ဖြင့် Batch တစ်ခုလုံး Status Update
  • ရောက်ရှိစာရင်း ထုတ်ယူခြင်း — Facebook တွင် တင်ရန် ပုံချောပုံအဖြစ် (ဖုန်းနံပါတ်များ ဖုံးထားသည်) — လက်ရေးစာရင်း အစားထိုး

ထိုင်း/ဆိပ်ကမ်းဘက် ပို့ဆောင်သူအတွက်

  • ဖုန်းမှ Login ဝင်၍ မိမိထံ လွှဲထားသော ပါဆယ်စာရင်း
  • လက်ခံသူကို တစ်ချက်နှိပ်ဖုန်းခေါ်၊ Call Log
  • ပို့ပြီး / မအောင်မြင် / ပြန်ပို့ မှတ်တမ်း

Admin (စီမံခန့်ခွဲသူ) အတွက်

  • လမ်းကြောင်းအလိုက် ဈေးနှုန်း/Tier ပြင်ဆင်ခြင်း (Website ပေါ် ချက်ချင်းပြောင်း)၊ လမ်းကြောင်း ဖွင့်/ပိတ်
  • ရုံးခွဲအလိုက် ဝန်ထမ်း Account နှင့် ခွင့်ပြုချက်
  • Dashboard — လမ်းကြောင်း/ရုံးခွဲအလိုက် ပါဆယ်အရေအတွက်၊ ကီလို၊ ဝင်ငွေ၊ မရသေးသောငွေ
  • Excel ထုတ်ယူခြင်း၊ Audit Log (ဘယ်သူ ဘာပြင်သလဲ)
